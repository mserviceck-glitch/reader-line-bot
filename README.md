# LINE Document Reader — V2.2

บอทดึงข้อมูลทะเบียนรถด้วย AI สำหรับคัดลอกไปกรอกฟอร์มประกันภัย ตอบในแชต LINE ส่วนตัว ไม่ออกกรมธรรม์และไม่เขียนข้อมูลบัญชี

ระบบดึงข้อมูลจาก AI เพื่อช่วยให้ออกเอกสารเร็วขึ้น โปรดตรวจสอบข้อมูลอีกครั้งก่อนนำไปใช้งาน

## การใช้งาน

ส่งรูปของรถคันเดียวได้ไม่เกิน 5 รูป → กด อ่านข้อมูล → รับผล → ระบบล้างรายการอัตโนมัติ พร้อมส่งคันใหม่ ไม่ต้องยืนยัน กด ล้าง เพื่อยกเลิกรูปที่ค้างอยู่ได้

มีปุ่มลอย เลือกรูป / อ่านข้อมูล / ล้าง ผลแยกข้อมูลผู้เอาประกันภัยและข้อมูลรถตามช่องฟอร์ม ไม่มีรายการจุดที่ต้องตรวจ ไม่มีรหัสรถ พ.ร.บ. เลขตัวถังและเลขเครื่องยนต์เหลือเฉพาะ A-Z, a-z, 0-9 โดยไม่แทน O เป็น 0 หากไม่มีเลขดังกล่าวจะเว้นว่าง ช่องอื่นที่ไม่มีข้อมูลแสดงขีด

## ติดตั้งเครื่องใหม่

ต้องมี Docker Compose, โดเมนชี้มายัง VPS และพอร์ต 80/443 ที่เข้าถึงได้

```sh
cp .env.example .env
chmod 600 .env
```

กรอกกุญแจใน `.env` บนเซิร์ฟเวอร์โดยตรง และตั้ง BOT_DOMAIN เป็นชื่อโดเมนจริง ไม่ใส่ https:// จากนั้น:

```sh
sudo docker compose up -d
```

ตั้ง LINE Webhook เป็น `https://<โดเมน>/webhook` กด Verify แล้วเปิด Use webhook ตรวจสุขภาพที่ `/health` และเวอร์ชันที่ `/version` ซึ่งต้องได้ `form-v2.2`

## อัปเดต VPS เดิม

เก็บ `.env`, compose และ Caddyfile เดิมไว้ สำรอง app.py เดิม จากนั้นนำเฉพาะ app.py ใหม่นี้ไปแทนในโฟลเดอร์บริการเดิม แล้วรัน:

```sh
sudo docker compose up -d --no-deps --force-recreate bot
```

ตรวจ `/version` ให้ได้ `form-v2.2` หากมีปัญหา คืน app.py ที่สำรองและรันคำสั่งเดิม ไม่จำเป็นต้องแทน compose หรือ Caddyfile เดิมด้วยตัวอย่างติดตั้งใหม่ ไม่แก้บริการ Hermes

## ทดสอบและข้อจำกัด

```sh
python test_app.py
```

มีการทดสอบจำลองการรับรูป แยกผู้ใช้ ล้างรายการ การส่งผล และลายเซ็น webhook ไม่ใช่การรับประกันความแม่นยำ OCR หรือการทดสอบด้วยกุญแจจริง

ใช้ Python standard library และ OpenAI Responses API ค่าเริ่มต้น gpt-4.1-mini เปลี่ยนด้วย OPENAI_MODEL ได้ ผลอ่านส่งผ่าน LINE Push ซึ่งใช้โควตาข้อความ

รหัสรูปและผลชั่วคราวอยู่ในหน่วยความจำ ล้างหลังส่งผลสำเร็จ อายุรายการ 30 นาที ไม่บันทึกรูปหรือผลลงดิสก์ของบอท แต่ข้อความที่ส่งแล้วคงอยู่ใน LINE การตั้ง store=false ไม่ได้หมายถึงผู้ให้บริการไม่เก็บข้อมูลใดเลย

คิวและรายการค้างหายเมื่อรีสตาร์ท อ่านทีละงาน จำกัด 20 ครั้งต่อผู้ใช้และ 100 ครั้งรวมต่อวัน UTC ตัวนับเริ่มใหม่เมื่อรีสตาร์ท จึงไม่ใช่เพดานค่าใช้จ่ายที่รับประกัน

ห้าม commit `.env`, กุญแจ, รูปเอกสาร หรือข้อมูลลูกค้า Repository นี้มีเฉพาะโค้ดและค่าตัวอย่างว่าง
